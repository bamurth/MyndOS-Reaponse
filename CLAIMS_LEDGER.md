# CLAIMS_LEDGER — what can and cannot be said from this work (2026-09-10)

Evidence status vocabulary: **established** = reproduced from verified data by the code in this repo with uncertainty reported;
**provisional** = observed but depends on choices or a small N; **not supported** = tested and failed; **untested** = no analysis here.
Every entry names the analysis that backs it. Nothing here supports diagnosis, etiology, treatment selection or clinical utility.
