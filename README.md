# MyndOS response dynamics benchmark

CPU-only, reproducible benchmark of how concurrent physiology (EEG, cardiac)
responds to changes in cognitive demand, with task performance measured
alongside. See `PLAN.md` for the owner's brief, `STATUS.md` for live progress
and blockers, and `RESULTS.md` for actual outputs once they exist.

Raw data are never committed. `data/raw/` is gitignored.
